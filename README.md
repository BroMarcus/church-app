# Kingdom Network Production Alpha

Production rebuild using Next.js + Supabase.

Current Alpha: real authentication, automatic New Life Madera alpha membership, profile editing, church-only community posts, and permanent schema foundations for groups, courses, ministry, outreach, documents, media, events, fundraising, and schedules.

Environment variables: `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`.

CI validation note: current Media Library hardening is included in this build check branch.
